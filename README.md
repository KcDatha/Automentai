# Automent AI

Showcase website for Automent AI, an AI automation studio.

A single static page (`index.html`) with services, process, example use cases and contact sections. It supports light and dark mode and works at phone width.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit http://localhost:8000.
